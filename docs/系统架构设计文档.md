## 1. 架构概述

### 1.1 设计原则

本系统采用**分层架构**设计，遵循以下核心原则：

| 原则 | 说明 |
|------|------|
| **单一职责** | 每个模块专注于单一业务领域 |
| **低耦合高内聚** | 模块间依赖最小化，内部功能高度相关 |
| **可扩展性** | 支持水平扩展和功能扩展 |
| **安全性优先** | 多层次安全防护机制 |
| **高可用性** | 支持故障自动恢复和降级 |
| **可观测性** | 完善的日志、监控、追踪体系 |

### 1.2 架构风格

- **架构模式**: 分层架构（Layered Architecture）
- **通信模式**: RESTful API（同步）+ 消息队列（异步）
- **数据访问**: ORM + 原生SQL（复杂查询）
- **认证方式**: JWT Token + RBAC权限控制

## 2. 技术栈选型

### 2.1 最终选型决策

经过对比分析（详见《对比分析报告.md》），**最终选型为 Node.js 生态**：

#### 核心理由

1. **开发效率高**: TypeScript全栈统一，前后端技能复用
2. **生态成熟**: NestJS框架提供企业级开发能力
3. **性能优异**: 异步I/O天然适合高并发场景
4. **部署简单**: 单一运行时，容器化部署成本低
5. **社区活跃**: 问题解决快，第三方库丰富

### 2.2 技术栈清单

#### 后端技术栈

| 类别 | 技术 | 版本 | 说明 |
|------|------|------|------|
| **语言** | TypeScript | 5.3+ | 类型安全，提升代码质量 |
| **运行时** | Node.js | 20 LTS | 长期支持版本 |
| **框架** | NestJS | 10.x | 企业级Node.js框架 |
| **ORM** | Prisma | 5.x | 类型安全的现代ORM |
| **数据库** | PostgreSQL | 15+ | 关系型数据库，功能强大 |
| **缓存** | Redis | 7.x | 内存数据库，高性能缓存 |
| **认证** | Passport.js | 0.7+ | 认证中间件 |
| **Token** | jsonwebtoken | 9.x | JWT实现 |
| **文档** | Swagger | 7.x | OpenAPI 3.0规范 |
| **测试** | Jest | 29.x | 单元测试和集成测试 |
| **构建** | pnpm | 8.x | 高效的包管理器 |

#### 理由说明

**为什么选 NestJS**：
- ✅ 模块化架构，天然支持依赖注入
- ✅ 内置Swagger集成，API文档自动生成
- ✅ 装饰器语法，代码简洁优雅
- ✅ 完善的错误处理和管道验证
- ✅ 对微服务和GraphQL支持良好

**为什么选 Prisma**：
- ✅ 类型安全，TypeScript原生支持
- ✅ Schema即代码，数据库迁移管理简单
- ✅ 查询性能优秀，接近原生SQL
- ✅ 自动生成客户端，减少样板代码
- ✅ 支持PostgreSQL高级特性

**为什么选 PostgreSQL**：
- ✅ 开源免费，无商业限制
- ✅ 支持JSON/JSONB，灵活性高
- ✅ 全文检索、数组类型等高级功能
- ✅ 事务ACID支持完善
- ✅ 社区活跃，生态成熟

### 3.2 层次职责

#### 3.2.1 控制器层 (Controller Layer)

**职责**:
- 接收HTTP请求，解析参数
- 参数格式验证（使用class-validator）
- 调用服务层执行业务逻辑
- 返回统一格式的响应
- 异常捕获和错误响应

**示例代码结构**:
```typescript
@Controller('tickets')
@UseGuards(JwtAuthGuard, RolesGuard)
export class TicketController {
  constructor(private readonly ticketService: TicketService) {}

  @Post()
  @Roles('creator', 'admin')
  async createTicket(@Body() dto: CreateTicketDto) {
    return this.ticketService.create(dto);
  }
}
```

#### 3.2.2 服务层 (Service Layer)

**职责**:
- 核心业务逻辑实现
- 事务管理
- 跨模块服务调用
- 数据转换和聚合
- 业务规则校验

**示例代码结构**:
```typescript
@Injectable()
export class TicketService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly notificationService: NotificationService
  ) {}

  async create(dto: CreateTicketDto) {
    return this.prisma.$transaction(async (tx) => {
      const ticket = await tx.ticket.create({ data: dto });
      await this.notificationService.notifyAdmins(ticket);
      return ticket;
    });
  }
}
```

#### 3.2.3 数据访问层 (Repository Layer)

**职责**:
- 数据库CRUD操作
- 复杂查询构建
- 数据库事务处理
- 缓存读写

**实现方式**:
- 简单查询：直接使用Prisma Client
- 复杂查询：封装Repository类
- 缓存操作：通过CacheService统一管理

## 6. 安全架构

### 6.1 认证机制

#### JWT Token 双Token方案

```
┌─────────────┐
│   Client    │
└──────┬──────┘
       │ 1. POST /login (username, password)
       ↓
┌─────────────┐
│   Server    │
└──────┬──────┘
       │ 2. Verify credentials
       │ 3. Generate tokens
       │
       ├── Access Token (短期，15min)
       │   └── Payload: { userId, role, exp }
       │
       └── Refresh Token (长期，7天)
           └── Payload: { userId, tokenId, exp }
           └── 存储在Redis（可撤销）
       
       │ 4. Return tokens
       ↓
┌─────────────┐
│   Client    │ 
│ Store tokens│
└─────────────┘

后续请求：
Header: Authorization: Bearer <access_token>

Token过期：
POST /auth/refresh { refreshToken }
→ 验证Refresh Token（检查Redis）
→ 签发新Access Token
```

### 6.2 授权机制（RBAC）

#### 角色权限矩阵

| 功能 | 创建者 | 处理人 | 主管 | 领导 | 管理员 |
|------|--------|--------|------|------|--------|
| 创建工单 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 查看所有工单 | ❌ | ❌ | 部门内 | 全部 | 全部 |
| 分配工单 | ❌ | ❌ | ❌ | ❌ | ✅ |
| 处理工单 | ❌ | 分配给自己的 | ❌ | ❌ | ✅ |
| 审核工单 | ❌ | ❌ | ✅ | ✅ | ✅ |
| 强制关闭 | ❌ | ❌ | ❌ | ❌ | ✅ |
| 查看报表 | ❌ | ❌ | 部门报表 | 全部 | 全部 |
| 用户管理 | ❌ | ❌ | ❌ | ❌ | ✅ |

#### 权限检查实现

```typescript
// 1. 守卫（Guard）实现
@Injectable()
export class RolesGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const requiredRoles = this.reflector.get<Role[]>('roles', context.getHandler());
    const request = context.switchToHttp().getRequest();
    const user = request.user;
    
    return requiredRoles.some(role => user.roles.includes(role));
  }
}

// 2. 装饰器使用
@Roles('admin', 'reviewer')
@UseGuards(JwtAuthGuard, RolesGuard)
@Post('tickets/:id/review')
async reviewTicket(@Param('id') id: string, @Body() dto: ReviewDto) {
  return this.reviewService.review(id, dto);
}
```

### 6.3 安全防护措施

#### 6.3.1 输入验证

- **参数验证**: class-validator + class-transformer
- **SQL注入防护**: Prisma ORM参数化查询
- **XSS防护**: helmet中间件，Content Security Policy

```typescript
// DTO验证示例
export class CreateTicketDto {
  @IsString()
  @Length(1, 100)
  @Transform(({ value }) => sanitize(value)) // XSS清理
  title: string;

  @IsString()
  @Length(1, 2000)
  description: string;

  @IsEnum(Priority)
  priority: Priority;
}
```

#### 6.3.2 CSRF防护

- **方案**: Double Submit Cookie
- **实现**: csurf中间件

#### 6.3.3 限流防护

- **登录接口**: 5次/分钟/IP
- **API接口**: 100次/分钟/用户
- **实现**: @nestjs/throttler

```typescript
@Throttle({ default: { ttl: 60000, limit: 5 } })
@Post('login')
async login(@Body() dto: LoginDto) {
  return this.authService.login(dto);
}
```

### 7.3 缓存更新策略

#### Cache-Aside Pattern（旁路缓存）

```typescript
async getTicket(id: string): Promise<Ticket> {
  // 1. 尝试从缓存获取
  const cached = await this.redis.get(`ticket:${id}`);
  if (cached) {
    return JSON.parse(cached);
  }
  
  // 2. 缓存未命中，查询数据库
  const ticket = await this.prisma.ticket.findUnique({ where: { id } });
  
  // 3. 写入缓存
  await this.redis.setex(`ticket:${id}`, 300, JSON.stringify(ticket));
  
  return ticket;
}

async updateTicket(id: string, data: UpdateTicketDto): Promise<Ticket> {
  // 1. 更新数据库
  const ticket = await this.prisma.ticket.update({
    where: { id },
    data
  });
  
  // 2. 删除缓存（下次读取时重建）
  await this.redis.del(`ticket:${id}`);
  
  return ticket;
}
```

### 7.4 缓存穿透防护

**问题**: 查询不存在的数据，绕过缓存直击数据库

**方案**: 布隆过滤器 + 空值缓存

```typescript
async getTicket(id: string): Promise<Ticket | null> {
  // 1. 布隆过滤器快速判断
  const exists = await this.bloomFilter.exists(id);
  if (!exists) {
    return null; // 一定不存在
  }
  
  // 2. 查询缓存
  const cached = await this.redis.get(`ticket:${id}`);
  if (cached) {
    return cached === 'NULL' ? null : JSON.parse(cached);
  }
  
  // 3. 查询数据库
  const ticket = await this.prisma.ticket.findUnique({ where: { id } });
  
  // 4. 缓存结果（包括空值）
  if (ticket) {
    await this.redis.setex(`ticket:${id}`, 300, JSON.stringify(ticket));
  } else {
    await this.redis.setex(`ticket:${id}`, 60, 'NULL'); // 空值缓存TTL较短
  }
  
  return ticket;
}
```
