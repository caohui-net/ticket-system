## 系统介绍

学校工单管理系统是一个专为学校设计的综合性工单管理平台，帮助学校各部门高效处理和跟踪各类事务请求。

### 主要特性

✅ **多角色权限管理** - 支持管理员、处理人员、普通用户三种角色  
✅ **完整工单流程** - 从创建、分配、处理到完成的全流程管理  
✅ **实时通知** - 工单状态变更实时通知相关人员  
✅ **统计分析** - 多维度数据统计和可视化报表  
✅ **附件管理** - 支持工单附件上传和下载  
✅ **操作日志** - 完整记录工单处理历史  

### 适用场景

- 🔧 设备报修管理
- 📝 行政事务处理
- 💻 IT服务请求
- 📚 图书借阅管理
- 🏫 教室申请管理
- 📞 投诉建议处理

## 快速上手

### 首次登录

1. 打开浏览器，访问系统地址（如：http://your-school-domain.com）
2. 输入管理员提供的用户名和密码
3. 首次登录建议修改密码

### 修改密码

1. 点击右上角用户头像
2. 选择"个人设置"
3. 在"安全设置"中修改密码
4. 新密码要求：至少8位，包含字母和数字

```

├── Logo（点击返回首页）
├── 工单管理
├── 统计报表

└── 用户菜单
    ├── 个人信息
    ├── 通知中心
    └── 退出登录
```

## 用户角色

### 管理员 (Admin)

**权限：**
- ✅ 查看所有工单
- ✅ 分配工单给处理人员
- ✅ 管理用户账号
- ✅ 配置系统参数
- ✅ 查看统计报表
- ✅ 导出数据

**典型工作流：**
1. 查看待分配工单
2. 根据工单类型分配给合适的处理人员
3. 监控工单处理进度
4. 处理异常和投诉

### 处理人员 (Handler)

**权限：**
- ✅ 查看分配给自己的工单
- ✅ 更新工单状态
- ✅ 添加处理备注
- ✅ 上传处理结果
- ✅ 完成或关闭工单

**典型工作流：**
1. 查看待处理工单列表
2. 领取工单并开始处理
3. 更新处理进度
4. 完成工单并添加处理说明

### 普通用户 (User)

**权限：**
- ✅ 创建新工单
- ✅ 查看自己的工单
- ✅ 查看工单处理进度
- ✅ 对已完成工单进行评价
- ✅ 接收工单通知

**典型工作流：**
1. 创建工单并描述问题
2. 等待分配和处理
3. 查看处理进度
4. 确认完成并评价

## 功能模块

### 登录与认证

#### 登录

1. 访问系统登录页面
2. 输入用户名和密码

2. 输入注册邮箱
3. 查收重置密码邮件
4. 点击邮件中的链接设置新密码

### 工单管理

#### 创建工单

**步骤：**

1. 点击"创建工单"按钮
2. 填写工单信息：
   - **标题**：简明扼要描述问题（必填）
   - **类别**：选择工单类型（必填）
   - **优先级**：选择紧急程度（必填）
   - **描述**：详细说明问题（必填）
   - **附件**：上传相关图片或文件（可选）
3. 点击"提交"创建工单

**工单类别：**
- 设备报修
- IT服务
- 行政事务
- 教学支持
- 其他

**优先级说明：**
- 🔴 **紧急**：影响正常工作，需要立即处理（如设备故障）
- 🟠 **高**：重要但不紧急，需尽快处理（如功能异常）
- 🟡 **中**：一般问题，正常排队处理（如咨询）
- 🟢 **低**：不影响工作，有空处理（如建议）

**填写技巧：**
- ✅ 标题简洁明了，如"教室301投影仪无法开机"
- ✅ 描述具体详细，包含时间、地点、现象
- ✅ 附件清晰，图片建议小于5MB
- ❌ 避免模糊表述，如"设备坏了"

#### 查看工单

**我的工单列表：**

```
工单列表
├── 全部工单
├── 待处理（新建、已分配）
├── 处理中
├── 已完成
└── 已关闭
```

**筛选和搜索：**
- 按状态筛选：待处理、处理中、已完成
- 按优先级筛选：紧急、高、中、低
- 按类别筛选：设备报修、IT服务等
- 关键词搜索：输入标题或描述关键词

**工单详情：**

点击工单可查看：
- 基本信息：标题、状态、优先级、类别
- 详细描述
- 附件列表
- 处理进度
- 操作日志
- 评价反馈（已完成工单）

#### 更新工单状态（处理人员）

**状态流转：**

```
新建 → 已分配 → 处理中 → 已完成 → 已关闭
  ↓       ↓        ↓
待分配   待处理   进行中
```

**操作步骤：**

1. 进入工单详情页
2. 点击"更新状态"按钮
3. 选择新状态并添加备注
4. 点击"确认"保存

**处理建议：**
- 领取工单后及时更新为"处理中"
- 定期更新处理进度
- 遇到问题及时添加备注
- 完成后详细说明处理结果

#### 工单评价（普通用户）

工单完成后，创建人可以对处理结果进行评价：

1. 进入已完成的工单详情
2. 点击"评价"按钮
3. 选择满意度：满意、一般、不满意
4. （可选）添加评价内容
5. 点击"提交"完成评价

### 通知中心

#### 查看通知

1. 点击顶部导航栏的"通知"图标
2. 未读通知显示红点提示
3. 点击通知查看详情

#### 通知类型

**工单相关：**
- 🔵 工单创建成功
- 🟢 工单已分配给处理人员
- 🟡 工单状态更新
- ✅ 工单已完成
- 📝 工单有新备注

**系统通知：**
- 📢 系统公告
- 🔔 密码过期提醒
- ⚠️ 异常提醒

#### 通知设置

1. 进入"个人设置"
2. 选择"通知设置"
3. 配置接收方式：
   - 站内通知（默认开启）
   - 邮件通知（可选）
4. 保存设置

### 系统设置

#### 用户管理

**添加用户：**

1. 进入"系统设置" → "用户管理"
2. 点击"添加用户"
3. 填写用户信息：

1. 在用户列表找到目标用户

1. 在用户列表找到目标用户

## 常见问题

### 登录问题

**Q1: 忘记密码怎么办？**

A: 点击登录页面的"忘记密码"，输入注册邮箱，按照邮件提示重置密码。如未收到邮件，请联系管理员。

**Q2: 账号被锁定怎么办？**

A: 密码连续输入错误5次后，账号将被锁定30分钟。可以等待30分钟后再试，或联系管理员解锁。

**Q3: 为什么无法登录？**

A: 可能的原因：
- 用户名或密码错误
- 账号已被禁用
- 浏览器Cookie被禁用
- 网络连接问题

### 工单问题

**Q4: 工单提交后多久会被处理？**

A: 
- 紧急工单：2小时内响应
- 高优先级：4小时内响应
- 中优先级：1个工作日内响应
- 低优先级：3个工作日内响应

**Q5: 如何加快工单处理？**

A: 
- 选择正确的工单类别
- 详细描述问题和位置
- 上传清晰的图片
- 选择合适的优先级
- 及时响应处理人员的询问

**Q6: 可以撤销已提交的工单吗？**

A: 
- 未分配的工单可以撤销
- 已分配或处理中的工单需要联系处理人员或管理员

**Q7: 工单完成后发现还有问题怎么办？**

A: 可以在评价时选择"不满意"并说明问题，或创建新的关联工单。

### 附件问题

**Q8: 支持上传哪些类型的文件？**

A: 支持以下格式：
- 图片：JPG, PNG, GIF
- 文档：PDF, DOC, DOCX, XLS, XLSX
- 压缩包：ZIP, RAR

**Q9: 单个文件大小限制是多少？**

A: 单个文件最大10MB，单个工单最多可上传5个附件。

**Q10: 如何下载附件？**

A: 在工单详情页面，点击附件列表中的文件名即可下载。

### 通知问题

**Q11: 为什么没有收到通知？**

A: 检查以下设置：
- 通知设置是否开启
- 邮箱地址是否正确
- 邮件是否被拦截到垃圾箱
- 浏览器通知权限是否开启

**Q12: 如何关闭某类通知？**

A: 进入"个人设置" → "通知设置"，取消勾选不需要的通知类型。

### 其他问题

**Q13: 系统支持哪些浏览器？**

A: 建议使用以下浏览器的最新版本：
- Chrome (推荐)
- Edge
- Firefox
- Safari

**Q14: 移动端可以使用吗？**

A: 系统支持响应式设计，可以在手机浏览器中使用。暂无独立APP。

**Q15: 数据会定期备份吗？**

A: 系统每天自动备份数据，保留最近30天的备份。

**Q16: 如何联系技术支持？**

A: 
- 创建IT服务类型的工单
- 发送邮件至：support@school.edu
- 拨打技术支持电话：内线XXX

## 使用技巧

### 高效使用建议

1. **及时更新工单**  
   创建工单后，关注通知并及时响应处理人员的询问。

2. **详细描述问题**  
   包含时间、地点、具体现象、已尝试的解决方法。

3. **合理设置优先级**  
   不要将所有工单都设为"紧急"，这会影响真正紧急的处理。

4. **上传清晰图片**  
   图片能帮助处理人员更快理解问题。

5. **使用搜索功能**  
   处理类似问题前，搜索是否有相关工单可以参考。

### 快捷键

- `Ctrl + K` - 快速搜索
- `Ctrl + N` - 创建新工单
- `Ctrl + /` - 显示快捷键帮助
