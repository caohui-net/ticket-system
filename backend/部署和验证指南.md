## 🔒 安全特性验证

### 1. 密码加密
```bash
# 数据库中的密码应该是BCrypt哈希
psql -U postgres -d ticket_system -c "SELECT username, LEFT(password, 20) as password_hash FROM users LIMIT 1;"
```

### 2. JWT Token机制
```bash
# 登录后检查Token格式
curl -s -X POST http://localhost:3000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"zhangsan","password":"Password123!"}' \
  | jq '.tokens'

# 输出应包含:
# {
#   "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
#   "refreshToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
#   "expiresIn": 900
# }
```

### 3. 登录失败锁定
```bash
# 连续5次错误密码登录
for i in {1..5}; do
  curl -s -X POST http://localhost:3000/api/v1/auth/login \
    -H "Content-Type: application/json" \
    -d '{"username":"zhangsan","password":"WrongPassword!"}' \
    | jq -r '.message'
done

# 第6次应返回: "账号已锁定，请15分钟后再试"
```

### 4. Token验证
```bash
# 尝试用无效Token访问
curl -X GET http://localhost:3000/api/v1/auth/me \
  -H "Authorization: Bearer invalid-token"

# 应返回 401 Unauthorized
```

## 🐛 故障排查

### 问题1: 数据库连接失败

**症状**: `Can't reach database server at localhost:5432`

**解决**:
```bash
# 检查PostgreSQL是否运行
sudo systemctl status postgresql

# 启动PostgreSQL
sudo systemctl start postgresql

# 验证连接
psql -U postgres -d ticket_system -c "SELECT 1;"
```

### 问题2: 端口3000已被占用

**症状**: `Port 3000 is already in use`

**解决**:
```bash
# 查找占用进程
lsof -i :3000

# 终止进程
kill -9 <PID>

# 或更改端口
PORT=3001 npm run start:dev
```

### 问题3: Prisma Client未生成

**症状**: `@prisma/client did not initialize yet`

**解决**:
```bash
npx prisma generate
npm run start:dev
```

### 问题4: 种子数据已存在

**症状**: `Unique constraint failed on the fields: (username)`

**解决**:
```bash
# 清空数据库重新初始化
npx prisma migrate reset --skip-seed
npm run prisma:seed
```
