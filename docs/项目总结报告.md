## 📊 项目概览

### 项目目标
构建一个生产级的企业工单管理系统，支持工单创建、分配、流转、审批、统计等全流程管理。

### 技术栈
- **后端**: NestJS + TypeScript + Prisma ORM + PostgreSQL
- **前端**: React 18 + TypeScript + Zustand + Ant Design + Vite
- **部署**: Docker + Docker Compose + Nginx
- **认证**: JWT (Access + Refresh Token)
- **安全**: BCrypt密码加密 + 账号锁定机制

## 🏆 技术难点和解决方案

### 1. JWT Token刷新机制
**问题**: Access Token过期后如何无缝刷新？

**解决方案**:
- 双Token机制（Access 15分钟 + Refresh 7天）
- Axios拦截器自动刷新
- Token过期前主动刷新
- 刷新失败自动跳转登录页

### 2. 账号安全保护
**问题**: 如何防止暴力破解？

**解决方案**:
- 5次失败自动锁定15分钟
- 失败次数记录到数据库
- 登录成功重置计数器
- 锁定期间拒绝所有登录

### 3. 密码安全存储
**问题**: 如何安全存储密码？

**解决方案**:
- BCrypt加密（10轮Salt）
- 配置化Salt轮数
- 密码验证使用compare方法
- 永不明文存储

### 4. 前端状态管理
**问题**: 如何管理复杂的应用状态？

**解决方案**:
- Zustand轻量级状态管理
- 模块化Store设计
- 持久化存储（localStorage）
- 自动同步Token
