## 系统要求

### 硬件要求

**最低配置：**
- CPU: 2核
- 内存: 4GB
- 磁盘: 20GB

**推荐配置：**
- CPU: 4核
- 内存: 8GB
- 磁盘: 50GB (SSD)

### 软件要求

**Docker部署：**
- Docker >= 20.10
- Docker Compose >= 2.0

**传统部署：**
- Node.js >= 18.0
- PostgreSQL >= 14.0
- Redis >= 7.0
- Nginx (可选，用于反向代理)

## 快速开始

### 使用Docker一键部署

```bash
# 1. 克隆项目
git clone <repository-url>
cd 工单项目

# 2. 复制环境变量文件
cp .env.production.example .env.production

# 3. 编辑环境变量（必须修改密码和密钥）
vim .env.production

# 4. 运行部署脚本
./deploy.sh
```

部署完成后访问：
- 前端：http://localhost
- 后端：http://localhost:3000
- API文档：http://localhost:3000/api/docs

## 环境配置

### 必须修改的配置项

在 `.env.production` 文件中，以下配置项**必须修改**：

```bash
# 数据库密码（强密码）
DB_PASSWORD=your-strong-password-here

# Redis密码（强密码）
REDIS_PASSWORD=your-redis-password-here

# JWT密钥（至少32个字符的随机字符串）
JWT_SECRET=your-super-secret-jwt-key-change-this-in-production-minimum-32-characters
JWT_REFRESH_SECRET=your-super-secret-refresh-key-change-this-in-production-minimum-32-characters
```

### 生成安全密钥

使用以下命令生成随机密钥：

```bash
# 生成JWT密钥
openssl rand -base64 32

# 或使用Node.js
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

### 可选配置项

**邮件通知（SMTP）：**

```bash
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password
SMTP_FROM=noreply@ticketing.com
```

**端口配置：**

```bash
FRONTEND_PORT=80        # 前端访问端口
BACKEND_PORT=3000       # 后端API端口
DB_PORT=5432            # PostgreSQL端口
REDIS_PORT=6379         # Redis端口
```

## Docker部署

### 生产环境部署

#### 1. 准备环境变量

```bash
# 复制示例文件
cp .env.production.example .env.production
```

```bash
curl http://localhost:3000/health/db

# 检查Redis连接
curl http://localhost:3000/health/redis

# 完整健康检查
curl http://localhost:3000/health/all
```


## 传统部署

### 1. 安装依赖

**Ubuntu/Debian：**

```bash
# 更新包管理器
sudo apt update

# 安装Node.js
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# 安装PostgreSQL
sudo apt install -y postgresql postgresql-contrib

# 安装Redis
sudo apt install -y redis-server

# 安装Nginx（可选）
sudo apt install -y nginx
```

### 2. 配置PostgreSQL

```bash
# 切换到postgres用户
sudo -u postgres psql

# 创建数据库和用户
CREATE DATABASE ticketing;
CREATE USER ticketing WITH ENCRYPTED PASSWORD 'your-password';
GRANT ALL PRIVILEGES ON DATABASE ticketing TO ticketing;
\q
```

### 3. 配置Redis

```bash
# 编辑Redis配置
sudo vim /etc/redis/redis.conf

# 设置密码
requirepass your-redis-password

# 重启Redis
sudo systemctl restart redis
```

### 4. 部署后端

```bash
cd backend

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
vim .env

# 运行数据库迁移
npx prisma migrate deploy

# 构建应用
npm run build

# 使用PM2启动（推荐）
npm install -g pm2
pm2 start dist/main.js --name ticketing-backend

# 或直接启动
npm run start:prod
```

### 5. 部署前端

```bash
cd frontend

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env
vim .env

# 构建应用
npm run build

# 使用Nginx服务静态文件
sudo cp -r dist/* /var/www/html/
```

### 6. 配置Nginx反向代理

创建 `/etc/nginx/sites-available/ticketing`：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端
    location / {
        root /var/www/html;
        try_files $uri $uri/ /index.html;
    }

    # 后端API
    location /api {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 健康检查
    location /health {
        proxy_pass http://localhost:3000/health;
    }
}
```

启用配置：

```bash
sudo ln -s /etc/nginx/sites-available/ticketing /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

## 故障排查

### 后端无法启动

**检查日志：**

```bash
docker-compose -f docker-compose.prod.yml logs backend
```

**常见问题：**

1. **数据库连接失败**
   - 检查 `DATABASE_URL` 配置
   - 确认PostgreSQL服务运行正常
   - 检查数据库凭据是否正确

2. **端口被占用**
   - 检查端口是否被其他服务占用
   - 修改 `.env.production` 中的端口配置

3. **权限问题**
   - 检查文件权限：`chmod 755 deploy.sh`
   - 检查数据卷权限

### 前端无法访问

**检查Nginx配置：**

```bash
sudo nginx -t
sudo systemctl status nginx
```

**检查前端构建：**

```bash
cd frontend
npm run build
```

### 数据库迁移失败

```bash
# 查看迁移状态
npx prisma migrate status

# 重置数据库（开发环境）
npx prisma migrate reset

# 手动应用迁移
npx prisma migrate deploy
```

### Redis连接失败

```bash
# 检查Redis服务
docker-compose -f docker-compose.prod.yml logs redis

# 测试Redis连接
redis-cli -h localhost -p 6379 -a your-password ping
```

## 安全建议

### 1. 密码和密钥安全

- ✅ 使用强密码（至少16个字符，包含大小写字母、数字、符号）
- ✅ 定期更换密钥和密码
- ✅ 不要将 `.env.production` 提交到Git仓库
- ✅ 使用密钥管理服务（如AWS Secrets Manager、HashiCorp Vault）

### 2. 网络安全

- ✅ 启用HTTPS（使用Let's Encrypt免费证书）
- ✅ 配置防火墙，只开放必要端口
- ✅ 使用VPN或专用网络访问数据库
- ✅ 启用CORS白名单

### 3. 应用安全

- ✅ 定期更新依赖包
- ✅ 启用速率限制
- ✅ 配置日志审计
- ✅ 定期备份数据

### 4. 数据库安全

- ✅ 定期备份数据库
- ✅ 限制数据库访问IP
- ✅ 使用强密码
- ✅ 启用SSL连接

### 配置HTTPS

使用Let's Encrypt：

```bash
# 安装Certbot
sudo apt install certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d your-domain.com

# 自动续期
sudo certbot renew --dry-run
```
