### 2. 架构模式

**选择**: 分层架构（三层）
- 表现层（Controller）
- 业务逻辑层（Service）
- 数据访问层（Repository）

**理由**:
- 职责分明，易于维护
- 符合Spring Boot最佳实践
- 团队熟悉度高

### 3. 认证方案

- **理由**: 无状态，易于扩展，跨域支持好
- **实现**: Spring Security + JWT
- **Token过期**: 2小时（可配置）
- **刷新机制**: Refresh Token
