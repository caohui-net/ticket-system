## 2. 认证页面

### 2.1 登录页 (P01)

**路由**: `/login`

**页面功能**
- 用户名/邮箱登录
- 密码输入(支持显示/隐藏)
- 记住我功能
- 忘记密码链接
- 注册入口

**页面布局**
```
┌─────────────────────────────────────┐
│                                     │
│          Logo + 系统名称             │
│                                     │
│    ┌─────────────────────────┐    │
│    │  用户名/邮箱              │    │
│    └─────────────────────────┘    │
│                                     │
│    ┌─────────────────────────┐    │
│    │  密码        [👁️]         │    │
│    └─────────────────────────┘    │
│                                     │
│    □ 记住我      忘记密码?         │
│                                     │
│    ┌─────────────────────────┐    │
│    │       登 录              │    │
│    └─────────────────────────┘    │
│                                     │
│         还没有账号? 立即注册        │
│                                     │
└─────────────────────────────────────┘
```

**表单字段**
| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| username | Input | 是 | 非空 |
| password | Password | 是 | 非空,最小6位 |
| remember | Checkbox | 否 | - |

**交互逻辑**
1. 输入用户名和密码
2. 点击登录按钮
3. 表单校验
4. 发送登录请求
5. 成功: 跳转到首页或来源页
6. 失败: 显示错误提示

**错误提示**
- "用户名或密码错误"
- "账号已被锁定,请联系管理员"
- "网络错误,请稍后重试"

**组件引用**
- `<Form>`, `<Input>`, `<Button>`, `<Checkbox>`, `<message>`

```
│    └─────────────────────────┘    │
│                                     │
│         已有账号? 立即登录          │
│                                     │
└─────────────────────────────────────┘
```

**表单字段**
| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| username | Input | 是 | 4-20位,字母数字下划线 |
| realName | Input | 是 | 2-20位中文/英文 |
| email | Input | 是 | 邮箱格式 |
| password | Password | 是 | 6-20位,包含字母数字 |
| confirmPassword | Password | 是 | 与密码一致 |
| agreement | Checkbox | 是 | 必须勾选 |

**密码强度规则**
- 弱: 6位以上
- 中: 包含字母+数字
- 强: 包含大小写字母+数字+特殊字符

## 3. 工单管理页面

```
├─────────────────────────────────────────────────────┤
│  [📊 卡片视图]  [📋 列表视图]     排序: [创建时间▼] │

│  « 上一页    1 2 3 4 5    下一页 »   共200条        │
└─────────────────────────────────────────────────────┘
```

**筛选条件**
| 字段 | 类型 | 选项 |
|------|------|------|
| 状态 | 多选 | 待分配/处理中/待审核/已驳回/已完成/已关闭 |
| 优先级 | 多选 | 紧急/高/中/低 |
| 类别 | 多选 | 技术支持/设备报修/行政事务等 |
| 时间范围 | 日期 | 最近7天/30天/自定义 |
| 创建人 | 搜索 | 按姓名搜索(管理员可用) |
| 处理人 | 搜索 | 按姓名搜索(管理员可用) |

**工单卡片信息**
- 工单编号
- 优先级标识(颜色+图标)
- 工单标题
- 创建人 → 处理人
- 创建时间(相对时间)
- 状态徽章

**表格列信息**
| 列名 | 宽度 | 说明 |
|------|------|------|
| 工单编号 | 150px | 可点击 |
| 标题 | 自适应 | 可点击 |
| 优先级 | 80px | 带颜色标签 |
| 状态 | 100px | 徽章显示 |
| 创建人 | 100px | - |
| 处理人 | 100px | - |
| 创建时间 | 180px | 完整时间 |
| 操作 | 120px | 查看/处理/关闭 |

**权限控制**
- 创建者: 只能看到自己创建的工单
- 处理人: 只能看到分配给自己的工单
- 审核人: 可以看到本部门的工单
- 管理员: 可以看到所有工单


**表单字段**
| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|---------|
| title | Input | 是 | 1-100字符 |
| category | Select | 是 | 从预设类别选择 |
| priority | Radio | 是 | urgent/high/medium/low |
| description | TextArea/RichText | 是 | 10-2000字符 |
| expectedTime | DateTimePicker | 否 | 不能早于当前时间 |
| attachments | Upload | 否 | 最多10个,每个≤10MB |

**草稿保存**
- 自动保存: 每30秒自动保存到LocalStorage
- 手动保存: 点击"保存草稿"按钮
- 草稿恢复: 下次打开页面提示恢复

**提交校验**
- 必填项检查
- 字符长度检查
- 附件大小检查
- 附件格式检查

## 8. 页面交互规范

### 8.1 页面跳转

**内部跳转**
- 使用React Router的`<Link>`组件
- 避免使用`<a>`标签

**外部跳转**
- 使用`<a target="_blank" rel="noopener noreferrer">`

### 8.2 加载状态

**全局加载**
- 页面级加载使用全屏Spin
- 组件级加载使用局部Spin

**骨架屏**
- 列表页使用骨架屏
- 详情页使用骨架屏

### 8.3 错误处理

**表单错误**
- 实时校验
- 错误提示在字段下方
- 红色边框+文字提示

**网络错误**
- 使用message.error提示
- 提供重试选项

### 8.4 确认操作

**危险操作需二次确认**
- 删除工单
