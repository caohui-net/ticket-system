## 📝 技术决策

### 1. JSON快照设计
采用Peppermint项目的设计模式，使用JSON字段存储用户快照：
```typescript
creatorSnapshot: {
  id: bigint,
  username: string,
  realName: string
}
```
**优点**：避免外键约束，支持用户删除后数据完整性

### 2. 工单编号策略
使用双编号系统：
- `id`: BigInt主键
- `number`: Int自增编号（#1, #2, #3...）

**优点**：友好、易读、便于口头交流

### 3. 状态时间戳
工单状态变更自动记录时间：
- `resolvedAt`: 标记为"已解决"时自动设置
- `closedAt`: 标记为"已关闭"时自动设置

### 4. 评论编辑历史
评论支持编辑，保留原始内容：
- `edited`: 是否编辑过
- `editedAt`: 编辑时间
- `previousContent`: 原始内容
