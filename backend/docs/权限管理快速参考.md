## 代码模板

### Controller守卫
```typescript
import { Controller, UseGuards } from '@nestjs/common';
import { JwtAuthGuard } from '../auth/guards/jwt-auth.guard';
import { PermissionsGuard } from '../permissions/guards/permissions.guard';
import { RequirePermissions } from '../permissions/decorators/require-permissions.decorator';

@Controller('resource')
@UseGuards(JwtAuthGuard, PermissionsGuard)
export class ResourceController {
  @Post()
  @RequirePermissions('resource:create')
  create() {}
  
  @Get()
  @RequirePermissions('resource:read')
  findAll() {}
}
```

### Service权限检查
```typescript
import { ForbiddenException } from '@nestjs/common';

// 检查单个权限
if (!user.permissions.includes('ticket:update')) {
  throw new ForbiddenException('无权更新工单');
}

// 检查多个权限（OR）
const hasPermission = user.permissions.some(p => 
  ['ticket:update', 'ticket:*', '*:*'].includes(p)
);

// 检查所有权
const isOwner = resource.creatorId === user.userId;
if (!hasPermission && !isOwner) {
  throw new ForbiddenException('无权操作');
}
```

### 获取当前用户权限
```typescript
import { CurrentUser } from '../auth/decorators/current-user.decorator';

@Get('me/permissions')
getMyPermissions(@CurrentUser() user: any) {
  // user.permissions 包含所有权限代码
  return user.permissions;
}
```

## API端点速查

### 权限管理
```bash
GET    /api/v1/permissions              # 获取所有权限
GET    /api/v1/permissions/:id          # 获取权限详情
POST   /api/v1/permissions              # 创建权限 (仅超级管理员)
PATCH  /api/v1/permissions/:id          # 更新权限 (仅超级管理员)
DELETE /api/v1/permissions/:id          # 删除权限 (仅超级管理员)
```

### 角色权限
```bash
GET    /api/v1/roles/:id/permissions              # 获取角色权限
POST   /api/v1/roles/:id/permissions              # 添加权限
PATCH  /api/v1/roles/:id/permissions              # 批量更新
DELETE /api/v1/roles/:id/permissions/:permId      # 移除权限
```

### 用户权限
```bash
GET /api/v1/users/me/permissions        # 当前用户权限
GET /api/v1/users/:id/permissions       # 指定用户权限
```

## 故障排查

### 权限验证失败
```
403 Forbidden: 需要以下权限: ticket:create
```
**解决**: 检查用户角色是否有该权限

### Token无效
```
401 Unauthorized: 用户不存在或已被禁用
```
**解决**: 重新登录获取新token

### 权限未加载
```
user.permissions is undefined
```
**解决**: 确认JWT策略已更新，包含权限加载逻辑

## 注意事项

⚠️ **重要提醒**:
1. 权限守卫顺序：`JwtAuthGuard` 必须在 `PermissionsGuard` 之前
2. 超级管理员 `*:*` 拥有所有权限
3. 通配符权限 `ticket:*` 匹配所有 `ticket:xxx`
4. 用户可以有多个角色，权限会自动合并去重
5. JWT token过期后需要刷新才能获取最新权限

## 常见问题

**Q: 如何添加新权限？**  
A: 修改 `permissions.seed.ts` 添加权限定义，然后重新运行种子脚本

**Q: 如何给角色添加权限？**  
A: 使用 POST `/api/v1/roles/:id/permissions` 接口

**Q: 权限变更后需要重新登录吗？**  
A: 是的，JWT token中的权限在登录时加载，需要重新登录才能生效

**Q: 如何实现"只能操作自己的资源"？**  
A: 在Service中检查资源所有权，配合权限双重验证
