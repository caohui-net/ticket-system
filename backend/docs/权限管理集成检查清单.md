- [ ] 可以正常编译（`npm run build`）

### ✅ 3. Controller集成

在您的Controller中添加：

- [ ] 导入 `JwtAuthGuard`
- [ ] 导入 `PermissionsGuard`
- [ ] 导入 `RequirePermissions` 装饰器
- [ ] 在类级别添加 `@UseGuards(JwtAuthGuard, PermissionsGuard)`
- [ ] 在需要权限的方法上添加 `@RequirePermissions('resource:action')`

**示例代码**:
```typescript
import { Controller, Get, Post, UseGuards } from '@nestjs/common';
import { JwtAuthGuard } from '../auth/guards/jwt-auth.guard';
import { PermissionsGuard } from '../permissions/guards/permissions.guard';
import { RequirePermissions } from '../permissions/decorators/require-permissions.decorator';

@Controller('your-resource')
@UseGuards(JwtAuthGuard, PermissionsGuard)  // ✅ 添加这行
export class YourController {
  
  @Post()
  @RequirePermissions('resource:create')    // ✅ 添加这行
  create() {
    // 您的业务逻辑
  }
  
  @Get()
  @RequirePermissions('resource:read')      // ✅ 添加这行
  findAll() {
    // 您的业务逻辑
  }
}
```

### ✅ 4. 权限配置

- [ ] 确认您的资源需要哪些权限（create, read, update, delete, etc.）
- [ ] 在 `permissions.seed.ts` 中添加您的权限定义
- [ ] 为相关角色分配权限
- [ ] 重新运行种子脚本

**权限命名规范**:
```typescript
// 格式: resource:action
'your-resource:create'   // 创建
'your-resource:read'     // 查看
'your-resource:update'   // 更新
'your-resource:delete'   // 删除
'your-resource:*'        // 所有操作
```

## 常见错误及解决方案

### ❌ 错误1: Cannot read property 'permissions' of undefined

**原因**: JWT策略未加载用户权限  
**解决**: 检查 `jwt.strategy.ts` 是否已更新

### ❌ 错误2: 403 Forbidden

**原因**: 用户没有所需权限  
**解决**: 
1. 检查用户角色是否正确
2. 检查角色是否有该权限
3. 运行 `GET /api/v1/users/me/permissions` 查看用户实际权限

### ❌ 错误3: 权限守卫不生效

**原因**: 守卫顺序错误或未添加  
**解决**: 确保使用 `@UseGuards(JwtAuthGuard, PermissionsGuard)`

### ❌ 错误4: 所有请求都返回403

**原因**: 所有用户都没有权限  
**解决**: 运行权限初始化脚本

## 快速验证命令

```bash
# 1. 检查权限表是否有数据
npx ts-node -e "
  const { PrismaClient } = require('@prisma/client');
  const prisma = new PrismaClient();
  prisma.permission.count().then(count => {
    console.log('权限数量:', count);
    if (count === 0) console.error('❌ 权限表为空，请运行种子脚本');
    else console.log('✅ 权限表已初始化');
    prisma.\$disconnect();
  });
"

# 2. 检查角色权限关联
npx ts-node -e "
  const { PrismaClient } = require('@prisma/client');
  const prisma = new PrismaClient();
  prisma.rolePermission.count().then(count => {
    console.log('角色权限关联数:', count);
    if (count === 0) console.error('❌ 角色权限未分配');
    else console.log('✅ 角色权限已配置');
    prisma.\$disconnect();
  });
"

# 3. 测试API（需要后端运行）
./test-permissions-api.sh
```
