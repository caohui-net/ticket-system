# 工单管理系统

工单全生命周期管理平台，支持创建、分配、处理、审核、关闭的完整流程。

## 📋 项目文档

| 文档 | 说明 | 版本 |
|------|------|------|
| [用户需求表.md](./用户需求表.md) | 完整的用户需求说明书（URD），18条需求 | v2.0 |
| [对比分析报告.md](./对比分析报告.md) | 与参考文档的对比分析，识别改进方向 | v1.0 |

## 🎯 核心特性

- ✅ **规范化流程**：5阶段标准化工单处理流程
- ✅ **多角色协同**：6类用户角色，权限清晰
- ✅ **全程追踪**：操作时间线，状态实时可见
- ✅ **驳回机制**：审核不通过可退回重新处理
- ✅ **自动通知**：关键节点自动推送消息
- ✅ **催办提醒**：超时工单自动提醒责任人
- ✅ **统计报表**：多维度数据分析

## 🔄 业务流程

```
创建工单 → 分配处理人 → 执行处理 → 提交结果 → 审核 → 关闭归档
                                                ↓ 驳回
                                          返回处理阶段
```

## 👥 用户角色

1. **工单创建者**：发起工单，跟踪进度
2. **处理人员**：执行任务，提交结果
3. **部门主管**：一级审核，通过/驳回
4. **分管领导**：二级审批（可选）
5. **系统管理员**：分配工单，权限管理
6. **报表查看者**：查看统计数据

## 📊 工单状态

- **草稿**：正在编辑，尚未提交
- **待分配**：等待管理员分配处理人
- **处理中**：处理人正在执行
- **待审核**：等待审核人审核
- **已驳回**：审核不通过，需重新处理
- **已完成**：审核通过，等待关闭
- **已关闭**：流程结束，已归档
- **已取消**：强制关闭

## 🎨 优先级

| 级别 | 响应时间 |
|------|----------|
| 紧急 | 2小时内 |
| 高 | 4小时内 |
| 中 | 1个工作日 |
| 低 | 3个工作日 |

## 📈 需求总览

**总需求数**：18条

**按阶段分布**：
- 阶段1：工单创建 - 2条
- 阶段2：工单分配 - 3条
- 阶段3：工单处理 - 3条
- 阶段4：工单审核 - 3条
- 阶段5：工单关闭 - 2条
- 查询统计 - 3条
- 通知提醒 - 2条

**按优先级分布**：
- P0（必须实现）：13条
- P1（重要）：4条
- P2（建议）：1条

## 🔧 非功能需求

- **性能**：页面加载≤2秒，支持200并发用户
- **安全**：RBAC权限控制，操作审计，数据加密
- **可用性**：99.5%可用性，响应式设计，多浏览器支持
- **兼容性**：Windows/macOS/Linux，Chrome/Firefox/Edge/Safari
