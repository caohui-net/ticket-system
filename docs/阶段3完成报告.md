## 🚀 部署准备

### 环境要求

**运行时**:
- Node.js >= 18.0
- PostgreSQL >= 14.0
- npm >= 9.0 或 pnpm >= 8.0

**开发工具**:
- VSCode (推荐)
- ESLint插件
- Prettier插件

### 启动步骤

**1. 安装依赖**:
```bash
cd backend
npm install
```

**2. 配置环境变量**:
```bash
cp .env.example .env
# 编辑.env，配置数据库连接
```

**3. 数据库迁移**:
```bash
# 方式1: 使用迁移脚本
./migrate.sh

# 方式2: 手动执行
npx prisma db push
npm run prisma:seed
```

**4. 启动服务**:
```bash
npm run start:dev
```

**5. 验证**:
- API文档: http://localhost:3000/api/docs
- 健康检查: http://localhost:3000/health

### 测试运行

```bash
npm test
```

```bash
npm run test:cov
```
